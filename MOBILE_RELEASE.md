# Ashen Realms — Android release pipeline

## Current state
- The game is packaged as a web build under `public/`.
- `public/index.html` is the mobile entry point.
- Capacitor configuration uses app id `com.ashenrealms.game`.
- The native Android project is intentionally generated by the build environment with `npx cap add android`; it is not hand-written here.

## Required build environment
Capacitor's Android documentation requires Android Studio and an Android SDK for native Android development. The Capacitor flow is: install `@capacitor/android`, run `npx cap add android`, then open/build the Android project. See the official Capacitor Android documentation.

## Important production blocker
The current game payment code calls `/api/create-order`. A locally bundled Capacitor app does not automatically execute the repository's serverless API as a local native endpoint. Before a production Android build is distributed, the app must point its payment/account calls at the deployed HTTPS backend and the backend must have the legally selected payment provider configured.

Do not put payment secrets inside the Android/web client.

## User action later
When the Android build is ready, the user/parent will need to install and test the generated APK/AAB on a real Android phone and complete the store's developer/account submission steps.
